# Приложение для работы с транспортными упаковками Честный ЗНАК

## Описание

Приложение на Python для автоматизации работы с системой маркировки товаров (markirovka.crpt.ru).

### Функционал

1. **Авторизация** с использованием электронной подписи (ГОСТ) через КриптоПро CSP
2. **Получение списка марок** вложений в транспортных упаковках
3. **Расформирование** транспортной упаковки
4. **Формирование новой** транспортной упаковки с вложениями

## Требования

### Системные требования

- Python 3.8+
- КриптоПро CSP 5.0+ (установленный и настроенный)
- Действующий сертификат электронной подписи для работы с Честным ЗНАКом

### Python зависимости

```bash
pip install requests
```

## Установка

1. Установите зависимости:
```bash
pip install requests
```

2. Убедитесь, что КриптоПро CSP установлен и настроен:
```bash
/opt/cprocsp/bin/amd64/cryptcp -version
```

3. Проверьте доступность сертификата:
```bash
/opt/cprocsp/bin/amd64/certmgr -list -store uMy
```

## Использование

### Базовый пример

```bash
python markirovka_app.py \
    --cert /path/to/cert.pem \
    --key /path/to/key.pem \
    --packages 046071384409093600 046071384409093601
```

### С указанием PIN-кода

```bash
python markirovka_app.py \
    --cert /path/to/cert.pem \
    --key /path/to/key.pem \
    --pin 12345678 \
    --packages 046071384409093600
```

### Из файла со списком упаковок

```bash
python markirovka_app.py \
    --cert /path/to/cert.pem \
    --key /path/to/key.pem \
    --file packages.txt
```

Формат файла `packages.txt`:
```
046071384409093600
046071384409093601
046071384409093602
```

## Параметры командной строки

| Параметр | Обязательный | Описание |
|----------|--------------|----------|
| `--cert` | Да | Путь к файлу сертификата |
| `--key` | Да | Путь к закрытому ключу |
| `--pin` | Нет | PIN-код контейнера |
| `--packages` | Да* | Список кодов упаковок (через пробел) |
| `--file` | Нет | Файл со списком упаковок |

*Требуется либо `--packages`, либо `--file`

## Алгоритм работы

Для каждой транспортной упаковки выполняется:

1. **Получение информации об агрегации**
   - Запрос к API Честный ЗНАК
   - Получение списка кодов вложений (children codes)

2. **Расформирование упаковки (дезагрегация)**
   - Отправка документа "Расформировать транспортную упаковку"
   - Вложения переходят в состояние "в обороте"

3. **Формирование новой упаковки (агрегация)**
   - Создание упаковки с кодом вида `00` + оригинальный код
   - Пример: `046071384409093600` → `00046071384409093600`
   - Вложения добавляются со статусом "IN_CIRCULATION" (в обороте)

## Программный интерфейс (API)

Приложение можно использовать как библиотеку:

```python
from markirovka_app import MarkirovkaApp

# Инициализация
app = MarkirovkaApp(
    cert_path='/path/to/cert.pem',
    key_path='/path/to/key.pem',
    pin='12345678'
)

# Вход в систему
if app.login():
    # Обработка упаковок
    results = app.process_packages(['046071384409093600'])
    
    # Анализ результатов
    for item in results['processed']:
        print(f"{item['original']} -> {item['new']}")
```

## Классы приложения

### `MarkirovkaApp`
Основной класс приложения, предоставляет высокоуровневый интерфейс.

### `MarkirovkaAPIClient`
Клиент для работы с API Честный ЗНАК:
- `authenticate()` - аутентификация с ЭП
- `get_aggregation_info(sscc)` - получение информации об упаковке
- `disaggregate(sscc, children)` - расформирование упаковки
- `aggregate(new_sscc, children, status)` - формирование упаковки

### `CryptoProCSP`
Класс для работы с КриптоПро CSP:
- `sign_data(data)` - подпись данных ГОСТ
- `get_cert_info()` - информация о сертификате

## Примечания

1. **Безопасность**: Никогда не передавайте PIN-код через переменные окружения или логи
2. **Сертификат**: Убедитесь, что сертификат действителен и имеет права на работу с API Честный ЗНАК
3. **Тестирование**: Рекомендуется сначала протестировать на тестовом контуре
4. **Лимиты API**: Учитывайте ограничения API Честный ЗНАК по количеству запросов
