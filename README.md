# Приложение для работы с системой маркировки Честный ЗНАК

## Версия 2.1

Приложение для автоматизации работы с транспортными упаковками маркированных товаров через API системы маркировки (markirovka.crpt.ru).

## Возможности

1. **Интерактивный выбор сертификата ЭП** - выбор из установленных в системе сертификатов
2. **Автоматический выбор по отпечатку** - указание сертификата через параметр командной строки
3. **Получение списка марок** вложений в транспортных упаковках
4. **Расформирование транспортной упаковки** 
5. **Формирование новой упаковки** с префиксом "00" с вложениями в состоянии "в обороте"

## Требования

- Python 3.8+
- КриптоПро CSP 5.0+ (обязательно для работы с реальной ЭП)
- Установленный сертификат электронной подписи
- Библиотека `requests`: `pip install requests`

## Установка

```bash
# Установка зависимостей
pip install requests

# Для Linux добавьте пути к утилитам КриптоПро в PATH
export PATH=$PATH:/opt/cprocsp/bin/amd64
```

## Использование

### Режимы выбора сертификата

#### 1. Интерактивный выбор (по умолчанию)

При запуске без параметра `--thumbprint` приложение предложит выбрать сертификат из списка доступных:

```bash
python markirovka_app_v2.py --packages 046071384409093600
```

#### 2. Выбор по отпечатку сертификата

Укажите отпечаток сертификата (полный или последние символы):

```bash
python markirovka_app_v2.py --packages 046071384409093600 --thumbprint ABCD1234567890
```

или краткая форма:

```bash
python markirovka_app_v2.py -p 046071384409093600 -t ABCD1234567890
```

#### 3. Тестовый режим (без реальной ЭП)

Для тестирования без подключенного сертификата:

```bash
python markirovka_app_v2.py --packages 046071384409093600 --test-mode
```

### Обработка нескольких упаковок

```bash
python markirovka_app_v2.py --packages 046071384409093600 046071384409093601 046071384409093602
```

### Просмотр справки

```bash
python markirovka_app_v2.py --help
```

## Алгоритм работы

Для каждой указанной упаковки выполняется:

1. **Получение состава упаковки** - запрос к API для получения списка кодов марок во вложениях
2. **Расформирование упаковки** - операция разформирования исходной упаковки (например, `046071384409093600`)
3. **Формирование новой упаковки** - создание упаковки с префиксом "00" (например, `00046071384409093600`) с теми же вложениями в статусе "IN_CIRCULATION" (в обороте)

## Примечания

### Для Windows

Убедитесь, что утилиты КриптоПро доступны в PATH:
```
C:\Program Files\Crypto Pro\CSP
```

### Для Linux

Добавьте пути к утилитам в ~/.bashrc или ~/.profile:
```bash
export PATH=$PATH:/opt/cprocsp/bin/amd64:/opt/cprocsp/bin/ia32
```

Проверьте установку:
```bash
certmgr -version
cryptcp -version
```

## Возможные ошибки и решения

### "Утилита certmgr не найдена"
- Убедитесь, что КриптоПро CSP установлен
- Добавьте пути к утилитам в переменную окружения PATH

### "Не найдено сертификатов с закрытым ключом"
- Проверьте наличие установленных сертификатов через `certmgr -list -store uMy`
- Убедитесь, что у сертификата есть связанный закрытый ключ

### "Ошибка аутентификации"
- Проверьте срок действия сертификата
- Убедитесь, что сертификат выпущен аккредитованным УЦ
- Проверьте подключение к интернету
